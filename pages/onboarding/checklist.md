# New Hire Checklist

_Who does what, from the week before a new hire starts through day 90._

Managers: make a copy of this checklist for each new hire and share it with them and their buddy. Owners are listed so nothing falls between People Operations, the manager, the buddy, and the contract lead.

## Before Start Date

| Task | Owner |
| --- | --- |
| Offer signed; employment or contractor agreement complete | People Operations |
| Rippling account, Focus Google Workspace account, and Slack invite created | People Operations |
| Laptop ordered and confirmed to arrive on or before Day 1 | Manager |
| Onboarding buddy assigned and briefed on the new hire's plan and Day 1 schedule | Manager |
| Three-month plan drafted from the practice template | Manager |
| Added to the onboarding calendar and the next cohort week sessions | People Operations |
| Added to the project's Google group and Focus-internal project Slack channel | Manager |
| Contract onboarding started: prime or client access requests, background checks, and, for subcontracts, a copy of the Focus onboarding docs for the program | Delivery or contract lead |
| Welcome note sent with contact info; Day 1 coffee or lunch scheduled | Buddy |

## Day 1

| Task | Owner |
| --- | --- |
| 1:1 with manager: role, three-month plan, first week | Manager + new hire |
| Morning check-in and informal coffee or lunch | Buddy |
| Access confirmed: Google Workspace, Slack, Rippling | New hire |
| Slack profile photo and email signature set up | New hire |
| 2-factor authentication on Google and Slack | New hire |

## Week 1

| Task | Owner |
| --- | --- |
| Practice or contract team lunch (DoorDash gift cards via People Operations) | Manager |
| Meet the project team | Delivery or contract lead |
| Recurring 1:1s set up with manager and with project or tech lead | New hire |
| Knows how to log time for their contract; recording time daily | New hire |
| 30-minute check-in; walkthrough of Focus tools and Slack channels | Buddy |
| Read key handbook pages and complete the handbook acknowledgment | New hire |
| Project tool access requested (client Slack or Teams, ticketing, wiki, repositories) | New hire + contract lead |

## Cohort Week (Second Week of the Month)

| Task | Owner |
| --- | --- |
| Mission, values, and how we work | CEO |
| Engineering, Delivery, and Design practice intros | Practice leads |
| People Operations walkthrough: Rippling, timesheets, benefits, PTO, JV systems | People Operations |

## Weeks 2–4

| Task | Owner |
| --- | --- |
| Contract onboarding complete; for subcontracts, prime onboarding done with the prime's buddy | New hire + contract lead |
| Intro conversation with practice lead; joined practice channel and community of practice | New hire + practice lead |
| Weekly 30-minute check-ins; introductions to other project and practice teams | Buddy |
| First assignment underway | New hire + project lead |
| 30-day check-in on the three-month plan | Manager |

## Month 2

| Task | Owner |
| --- | --- |
| Weekly buddy check-ins; feedback on onboarding so far | Buddy |
| All tool access and setup complete | New hire |
| Learning goal or shadowing opportunity identified | New hire + practice lead |
| 60-day check-in on the three-month plan | Manager |

## Month 3

| Task | Owner |
| --- | --- |
| Biweekly buddy check-ins; transition to a normal working relationship | Buddy |
| 90-day check-in; end-of-introductory-period conversation | Manager |
| 90-day onboarding feedback form completed | New hire |
| Buddy experience feedback shared with the onboarding program | Buddy |
